gitinspector (0.5.0)

	Major release with a new HTML theme, support for multiple repositories
	and many fixes.

	* Several repositories can be analyzed in one run, merged into a
	  unified report.
	* JSON output format.
	* Responsive HTML theme based on Bootstrap, with sortable tables, pie
	  charts and buttons that reveal minor authors.
	* New -M/--forcemonths option that shows both monthly and weekly
	  statistics together with -w.
	* Go, PHP, Swift and TypeScript source files are analyzed by default
	  and get metrics.
	* Comment recognition for Go, Rust, Robot Framework, Lilypond,
	  TypeScript, JSX, CSV and TSV files.
	* "Rows" are now called "lines" throughout the output. The JSON and
	  XML keys "rows" and "modified_rows" were renamed accordingly.
	* Dutch, Korean, Portuguese and Russian translations.
	* A French error message no longer loses the path of the repository
	  it complains about, and the Chinese metrics output no longer prints
	  the cyclomatic complexity density with the wrong precision.
	* Author emails are included in the JSON and HTML output.
	* The analyzed branch of each repository is named in the output.
	* Commits on merged branches are no longer lost during analysis.
	* --version and --help are answered outside a git repository again,
	  instead of complaining that the current directory is not one.
	* An argument that names a missing directory, or a file rather than a
	  directory, is reported as an error instead of a traceback.
	* Runs on Python 3 again and keeps running on Python 2.7.
	* No more line buffering warnings from Python 3.8 and later.
	* Files without an extension are blamed when asked for with * or **.
	* Blamed lines are attributed to the newest name of an author, which
	  earlier depended on the timing of the analysis threads.
	* Tests that analyze real repositories and check the reports against
	  statistics gathered straight from git.
	* Names and paths with characters outside ASCII no longer crash the
	  analysis or the output.
	* A test harness that runs the analysis on generated repositories.
	* Example reports are published on GitHub Pages.
	* A Dockerfile that analyzes a repository mounted on /repo, for those
	  who would rather not install gitinspector.
	* Running out of memory while starting git no longer aborts the
	  analysis with an exception: gitinspector waits for its other git
	  processes to finish, continues with fewer of them and only gives up,
	  with a clear message, when git cannot be started at all.
	* An error inside an analysis thread, such as an invalid author or
	  email exclusion pattern, is reported instead of hanging gitinspector.

gitinspector (0.4.4)

	Minor release with some minor fixes.

	* Better support for additional terminals.
	* -f "**" now properly ignores binary files.

gitinspector (0.4.3)

	Minor release with updated language locales.


gitinspector (0.4.2)

	Minor release with many small, but great improvements.

	* The changes module is now threaded and uses all available cores. This
	  results in a significant speed up.
	* Printed extensions are now alphabetically sorted.
	* Ability to exclude commits with certain comments from statistics.
	* Support for C# code and comments.
	* Extensionless files can now be included in statistics.
	* Ability to include all file extensions by specifying "**".
	* Spanish translation.


gitinspector (0.4.1)

	Maintenance release fixing several issues found in the previous version.


gitinspector (0.4.0)

	Major update with many fixes and new features.

	* Support for remote repositories (git://, http(s)://, ssh://).
	* Code stability and age shown in blame output.
	* Support for cyclomatic complexity and cyclomatic complexity density
	  metrics.
	* Ability to exclude commit hashes (revisions) from statistics.
	* Improved HTML output.
	* Support for ADA, OCaml and Haskell comments.
	* Improved localization support for languages with multi-column
	  characters.
	* Many (big and small) bug fixes.
	* French translation.
	* German translation.


gitinspector (0.3.2)

	Maintenance release that adds several new features and bug fixes.

	* Better handling of terminals that have no encoding configured.
	* File extensions .cc and .hh scanned by default.
	* Support for bare repositories.
	* Support for comments in .xhtml, .jspx, and .scala files.
	* The ability to filter out statistics from specific authors or
	  emails.
	* The flag --since now behaves correctly.
	* Italian translation.
	* Polish translation.


gitinspector (0.3.1)

	Minor release which adds support for gravatars.

	* A few minor bug fixes.
	* Chinese translation.
	* Support for gravatars in the HTML and XML outputs.
	* Improved responsibilities section in the HTML output.
	* Debian package now properly depends on git.


gitinspector (0.3.0)

	This is a major release with many new features.

	* Support for comments in LaTex (.tex) and PHP files.
	* Many bugfixes.
	* Localization support (English and Swedish for now).
	* Support for setting gitinspector options via git-config.
	* Support for regular expressions in conjunction with -x/--exclude.
	* New output format; "htmlembedded".
	* Support for Python packaging via setuptools.
	* Improved HTML output with new JQuery and flot versions.


gitinspector (0.2.2)

gitinspector (0.2.1)

gitinspector (0.2.0)
