gitinspector example outputs

Example reports for a number of open source projects, generated with the -HTlrm flags. See the gitinspector repository for the tool itself.

Every HTML link opens its report in a view of its own, picked by the parameters in the address; the theme, the light or dark mode and whether the minor authors are listed. Strip them off to get the view you last chose yourself.
